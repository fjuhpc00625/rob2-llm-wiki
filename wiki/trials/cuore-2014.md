# CUORE Trial (Marenzi et al., 2014)

- **原始來源**：`raw/01-cuore-marenzi-2014.md`
- **期刊**：*Journal of Cardiac Failure*, 2014;20(1):9–17
- **研究設計**：前瞻性隨機對照開放標籤試驗（`n = 56`；超濾組 27 人 vs 標準利尿劑組 29 人）
- **主要終點**：1 年內因鬱血性心衰竭再住院次數（CHF rehospitalizations）

## 驗證後 RoB 2 評量結果

| Domain | 風險等級 | 關鍵證據與規則依據 |
| :--- | :--- | :--- |
| **D1 隨機分派** | Some concerns | 1:1 隨機分派，但摘要與公開方法對分配隱藏細節著墨有限（依 [[rob2-decision-rules]] V3）。 |
| **D2 偏離介入** | Some concerns | Open-label 設計（醫材 vs 藥物無法盲化），1 年追蹤期間可能受共同照護影響。 |
| **D3 缺失資料** | Low | 住院期至 1 年追蹤之主要指標（再住院）完整追蹤。 |
| **D4 結果測量** | Some concerns | 「是否收治再住院」牽涉臨床醫師判斷，未盲化可能帶來些微偵測偏差。 |
| **D5 選擇性報告** | Some concerns | 未見公開事前詳細統計分析計畫（SAP）可供完全比對。 |
| **Overall Risk** | **Some concerns** | 無 High Domain，但多個關鍵面向存有疑慮（符合 V1）。 |

## 初學者白話解讀
這篇試驗顯示超濾可能減少一年內再住院，但因為人數較少（56 人）且醫師知道病人做過哪種治療，決定「要不要再收住院」時可能受主觀影響，因此可信度評為「有些疑慮」。
