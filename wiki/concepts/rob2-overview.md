# RoB 2 核心概念與 5 大偏差領域

**RoB 2（Revised Cochrane Risk-of-Bias tool for randomized trials，Sterne et al., BMJ 2019）** 是實證醫學領域最權威的工具，用來評估一篇隨機對照試驗（RCT）在**特定結果指標（Outcome）**上的偏差風險。

> 白話理解：就算論文的統計結果寫著 `p < 0.05`，如果研究設計或執行有漏洞，這個「有效」可能只是假象。RoB 2 就是在幫論文做**品質體檢**。

## 核心特色（與舊版 RoB 1 的最大差異）
1. **以「單一結果（Outcome）」為評估單位**：同一篇論文的「死亡率（客觀）」與「呼吸困難評分（主觀）」在 D3、D4、D5 的偏差風險可能完全不同，不能整篇一概而論。
2. **固定 5 大偏差領域（Domains）**：
   - [[d1-randomization]] — 隨機分派過程（題號 1.1–1.3）
   - [[d2-deviations]] — 偏離預期介入（題號 2.1–2.7）
   - [[d3-missing-data]] — 缺失結果資料（題號 3.1–3.4）
   - [[d4-outcome-measurement]] — 結果測量偏差（題號 4.1–4.5）
   - [[d5-selective-reporting]] — 選擇性報告結果（題號 5.1–5.3）
3. **引導問題 ＋ 確定性演算法**：先回答 22 題 Signaling Questions（`Y / PY / PN / N / NI`），再透過 [[rob2-decision-rules]] 自動映射到 `Low`、`Some concerns` 或 `High`。
